# 禾序饭堂 · 微信小程序

学生端使用原生微信小程序，以 JS、WXML 和 WXSS 实现。通过 Spring Boot `/campus` 接口使用校园 JWT、学生账号和数据库。

## 打开工程

1. 在项目根目录执行 `start.ps1`，启动原有 MySQL、Redis、Spring Boot 与网页同源代理。
2. 打开微信开发者工具，导入本目录 `miniprogram`，类型选择“小程序”，不使用云开发。本工程无需 npm 安装或构建。
3. `project.config.json` 已填写用户提供的小程序 AppID `wxb9ced89fe8c55eed`。微信扫码预览需登录该小程序有权限的微信账号。其他开发者应替换为自己的 AppID/测试号；只在本机游客调试时可改为 `touristappid`。
4. 本机模拟器默认请求 `http://127.0.0.1:15173/campus`，已设置开发阶段关闭域名校验。先运行后端与 Vite 再编译小程序。
5. 使用演示学生账号 `20260001` / `Campus@2026` 登录，或注册自己的 8 至 16 位学号。管理员账号在 Web 管理端使用。

## 手机真机与服务器

“我的 → 服务器设置”可填写服务器根地址，结尾不包含 `/campus`。保存后测试窗口接口，切换服务器会退出账号。当前地址保存在微信本地缓存中，不需要改代码。

- 模拟器：`http://127.0.0.1:15173`（Vite 转发 `/campus` 给本地后端）。
- 热点/局域网真机：需要一个手机可达的网页代理端口；电脑端 Vite 需监听局域网地址。示例启动命令：在 `web` 中运行 `npm.cmd run dev -- --host 0.0.0.0 --port 15174`，小程序里填 `http://电脑当前IPv4:15174`。热点重新连接可能分配新 IP。MySQL、Redis 不对手机开放。
- 正式使用：配置公网 HTTPS API 域名，并在微信公众平台设置 request 合法域名。生产环境不能依赖开发工具的域名校验开关。真机调试还需按当前微信开发者工具的调试设置处理域名校验。

在微信开发者工具点击“预览”生成小程序码，再用有权限的微信账号扫码。

## 已迁移功能

- 点餐：首页、窗口切换、分类筛选、搜索、收藏、库存展示、购物车增减与清空。
- 预约：今天/明天、可用时段、备注、餐具、服务端计价与库存核验、请求编号幂等。
- 订单：个人预约筛选、取餐码、模拟支付、取消、改约、完成后的评分与评价。页面显示时每五秒同步，离开页面停止轮询。
- 公告、按窗口提交反馈、查看反馈和工作人员回复。
- 学号登录、注册、会话恢复、退出登录、服务器连接配置。
- 菜品图片随工程打包，演示图片仍沿用原项目素材与来源说明。

## 登录和支付的实际范围

登录使用现有学号密码及 JWT，未接微信授权登录，不调用 `wx.login`，不把学生身份绑定为 OpenID。

在“预约”页的待支付卡片底部点击“去模拟支付”会打开收银台，显示订单金额和取餐窗口。选择“模拟失败”可重试，选择“取消付款”会返回待支付订单。确认模拟支付时调用现有 `/student/orders/{id}/pay`，服务端在 `payment-mode=demo` 时返回已支付订单和取餐码。此流程为本地演示，不发生资金交易。

## 结构

`app.*` 为小程序配置与公共样式，`pages/` 为六个原生页面，`utils/api.js` 负责请求、校园会话与展示数据适配，`assets/images/` 为本地图片。没有前端密码、AppSecret 或支付密钥。
