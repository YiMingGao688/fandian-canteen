# 饭点

学生端使用[原生微信小程序](miniprogram/README.md)。用微信开发者工具导入 `miniprogram/`，可调试点餐、预约、取餐凭证、评价和反馈。学生使用学号登录，支付目前为模拟流程。微信扫码预览需要有权限的 AppID 或测试号。

饭点是一个面向校园场景的食堂预约点餐与运营管理系统。学生可提前选择食堂窗口、菜品和取餐时段并提交预约；食堂工作人员在管理端接单、备餐和核销；管理员可维护菜品与库存、处理学生反馈并查看运营数据。

项目提供学生微信小程序、食堂管理后台和运营数据大屏。后端使用 Spring Boot 提供 API，数据存储使用 MySQL，并使用 Redis 缓存部分菜单数据。当前版本用于本地课程演示：支付为模拟流程，不会扣款；演示数据、图片和营养信息不代表真实经营数据。

## 系统入口

本机服务启动后可通过以下地址访问：

| 入口 | 地址 | 主要用途 |
| --- | --- | --- |
| 学生微信小程序 | 在微信开发者工具中[导入工程](miniprogram/README.md) | 浏览窗口和菜单、加入餐盘、预约取餐时段、查看订单和取餐码 |
| 食堂管理后台 | <http://127.0.0.1:15173/#/admin> | 工作人员处理订单和核销；管理菜品库存、查看概览、回复反馈 |
| 运营数据大屏 | <http://127.0.0.1:15173/#/screen> | 查看全校窗口汇总、经营图表和食堂运营示意模型 |

管理后台与大屏会校验登录身份和权限。小程序模拟器默认通过本机 15173 端口的代理访问校园 API。服务默认只监听本机地址，真机连接方式见[小程序说明](miniprogram/README.md)。

## 主要功能

- 学生注册登录，浏览窗口和菜品，搜索、收藏并使用购物车。
- 预约今天或明天的取餐时段，可填写备注并选择餐具；预约提交时按数据库价格计算，并在事务中扣减菜品库存和时段名额。
- 查看本人预约、进行模拟支付、取消或改约；预约完成后查看取餐码并提交评价。
- 工作人员按窗口权限接单、备餐、核销取餐码、维护本窗口菜品并回复反馈。
- 管理员跨窗口查看经营概览、预约订单、菜品库存与学生反馈。
- 运营大屏展示预约和核销汇总、菜品排名、分类占比、窗口订单状态及取餐时段情况；图表使用 ECharts，中央食堂示意模型使用 Three.js。大屏模型位置仅作视觉示意，不代表真实校园坐标。
- 大屏展示账号仅能读取脱敏汇总数据，不提供订单或菜品管理操作。

## 本地运行

当前提供 Windows PowerShell 启动脚本。首次运行前需准备 JDK 17、Maven、Node.js、Python，以及项目使用的 MySQL 和 Redis 程序。安装网页依赖、构建后端后启动：

```powershell
cd .\web
npm.cmd ci
cd ..
python -X utf8 .\scripts\build_backend.py
.\start.ps1
```

停止本项目服务：

```powershell
.\stop.ps1
```

默认端口为 Vite `15173`、Spring Boot `18088`、项目独立 MySQL `13316`、Redis `16379`。运行配置、数据库文件和服务数据保存在 Git 忽略的 `.local/` 目录；首次启动按项目本地运行配置准备数据库。`stop.ps1` 不会删除数据库文件。首次安装依赖和准备本机环境尚未做到全自动，详细要求与配置见下方用户手册。

## 支付说明

默认支付模式为本地模拟支付，不会扣款，也不代表真实支付渠道已经接入。项目保留支付宝沙箱联调配置入口；启用沙箱需要开发者自行准备有效的沙箱应用信息和回调地址，并将密钥保存在本机 `.local/` 配置中。不要把支付私钥或其他密钥提交到 Git。

## 项目结构

- `backend/`：Spring Boot 后端 API、业务服务和数据访问代码。
- `miniprogram/`：学生微信小程序。
- `web/`：Vue 3 管理后台、运营大屏和本地 API 代理。
- `database/`：数据库结构及本地演示数据脚本。
- `scripts/`：本地构建、运行、初始化和验证辅助脚本。
- `docs/`：需求规格、系统设计、用户手册和测试记录。
- `start.ps1`、`stop.ps1`：Windows 本地服务启动与停止入口。
- `.local/`：本机运行配置及服务数据，不提交到 Git。
