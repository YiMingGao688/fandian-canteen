## 2. API 检查范围

验证包含公开菜单和身份隔离、JWT 篡改拒绝、密码摘要不外泄、购物车增减/同窗口限制、requestId 幂等、价格从数据库计算、库存与时段额度事务、支付幂等、取消资源恢复、备餐状态迁移、改约、评价限制、窗口反馈隔离、管理员全校范围、大屏只读授权和字段脱敏。

并发检查使用 16 名隔离测试学生抢有限预约名额、以及在不同预约时段争用有限菜品库存；未超过时段容量/可售库存，结束后检查取消订单归还资源。**该测试不是 500 并发压力测试。**

## 5. 可复跑

保持本地服务运行，在项目目录 `campus-ordering` 执行：

```powershell
python -X utf8 .\scripts\verify_api.py
D:\node\node.exe .\scripts\verify_browser.mjs
```

验证脚本使用隔离本地数据库创建合成学生、预约、评价和反馈记录；不会连接生产库或真实支付。不要把 `.local/` 中的配置和账号密钥复制到提交包。
