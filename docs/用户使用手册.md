# 饭点用户使用手册

## 微信小程序入口

在微信开发者工具中导入项目的 `miniprogram/` 目录。启动本地服务后，可在模拟器使用学号登录并点餐。开发联调服务器默认为 `http://127.0.0.1:15173`，可在小程序“我的 → 服务器设置”修改。真机预览使用开发者工具生成的小程序码，手机需能访问配置的服务器。详细步骤见 [小程序说明](../miniprogram/README.md)。

小程序使用学号和密码登录，当前支付为模拟流程。

## 1. 启动与入口

在 Windows PowerShell 首次安装网页依赖并构建后端：

```powershell
cd <项目目录>\campus-ordering\web
npm.cmd ci
cd ..
python -X utf8 .\scripts\build_backend.py
.\start.ps1
```

服务启动后可在开发者工具打开学生小程序，并在浏览器打开以下工作入口。

- 食堂管理后台：<http://127.0.0.1:15173/#/admin>
- 运营数据大屏：<http://127.0.0.1:15173/#/screen>

关闭时在 PowerShell 执行 `cd <项目目录>\campus-ordering; .\stop.ps1`。停止脚本停止工作区拥有的服务，不删除数据库文件。默认只允许当前电脑本机访问，尚未开放真实手机通过 Wi-Fi 访问。

## 3. 学生微信小程序

1. 在“点餐”页先选窗口，再按分类查看菜品，也可以搜索或筛选收藏。
2. 点菜品右侧加号加入餐盘；同一餐盘只能选一个窗口，数量不能超过库存。
3. 点底部餐盘的“去预约”，选今天或明天的可用时段，可填写备注并选择是否需要餐具。
4. 点“确认预约”后，在“预约”页面打开订单并选择“模拟支付”，完成演示订单支付。
5. 在预约卡片查看状态和八位取餐码。“待支付”和“等待接单”的预约支持取消或改约。
6. 工作人员核销后，预约变为“已取餐”，可在订单卡片提交一次评价。
7. “公告”页面查看公告、向指定窗口提交反馈；“我的”页面查看预约/收藏入口和退出登录。

## 4. 管理后台

1. 打开“食堂管理后台”。未登录时会进入管理登录页；窗口或全校管理员登录后直接进入经营概览，刷新页面会复核当前会话。
2. “经营概览”查看数据库统计和图表；窗口账号只见所属窗口，管理员查看全校范围。
3. “预约订单”使用服务端分页查询完整历史，可按状态、取餐日期、关键词和窗口筛选；窗口账号始终只查询本窗口。工作人员使用“接单并备餐”和“标记备妥”推进状态。点击每行右侧省略号打开明细，可填写原因拒单或管理取消。只有待接单能拒单；已完成不可取消；支付退款失败时保留原状态。
4. 学生到窗出示八位取餐码后，在核销框输入并确认。只有对应窗口工作人员或管理员可核销，重复核销会被拒绝。
5. “菜品与库存”右上角可新增菜品，上传照片并填写名称、所属窗口、分类、单价、初始库存等资料。新菜品默认下架，可在表单选择在售；保存后定位到真实菜单中的记录。窗口账号只维护绑定窗口。编辑可维护完整资料，库存未修改时保留最新剩余库存；已有订单快照不变。删除要求先下架，且无历史订单或套餐引用。全校管理员还可通过“分类管理”新增、改名、排序、启停或删除无引用分类。
6. “学生反馈”查看范围内反馈并提交回复。
7. “运营设置 → 窗口与营业”维护真实窗口、位置、营业时间、默认时段容量和预约开关。管理员可新增窗口；窗口人员只能编辑绑定窗口，不能更换所属食堂。营业时间最多四段、每段至少二十分钟且不跨午夜；新预约及改约按保存后的区间校验。默认容量只影响新发布时段，已有时段保持原容量；暂停后已有订单仍可处理。
8. 全校管理员在“运营设置 → 工作账号”新增/编辑工作人员、管理员或只读大屏账号，可搜索、分页、绑定窗口、启停和重置密码。工作人员必须绑定窗口，不能停用或降级当前管理员。重置密码、调岗或更换绑定窗口后原会话失效；普通窗口账号没有工作账号管理入口。
9. 管理会话过期或密码被重置后会回到管理登录页。升级前的旧会话需要重新登录，原有体验账号密码保持不变。
10. 顶栏“运营数据大屏”会在新标签页打开，并继续校验当前管理员权限；用右上角“退出登录”结束管理会话。

## 5. 运营数据大屏

独立打开“运营数据大屏”，登录 `canteen_screen` 或管理员。展示全校预约、已核销收入、当前待取餐、窗口状态、预约时段、销量、分类偏好和近七日趋势。页面每 15 秒读取汇总数据，也可手动刷新或切换今日/明日预约视图。浏览器支持时可用“全屏展示”。该账号不显示学生姓名、学号、联系方式或取餐码，也无管理写操作。

中央为食堂运营沙盘，布局仅作示意。单击浮动窗口标注可切换下方窗口详情，也可拖动旋转视角；“场景巡航”开启缓慢环绕，“复位”恢复初始视角。近七日图展示已核销订单金额，按下单日期汇总；“窗口订单分布”展示所选预约日各窗口的已支付订单状态。

## 6. 说明

- 此版本是课程演示系统，不接入实际学校账户、微信支付或退款渠道。
- 本地种子数据和自动验证订单会影响图表统计，统计结果不代表真实食堂经营数据。
- 菜品照片和营养估值属于演示示意，使用时应替换为经授权的真实素材和核验数据。


## 经营报表与批量菜品操作

- 管理后台“运营设置 → 经营报表”选择取餐开始/结束日期，管理员可选择窗口，工作人员自动限定本窗口。查询成功后可导出 Excel；日期或窗口改变后先重新查询，最多 366 天。
- 收入只计已核销预约，退款金额单独列示；Excel 提供每日经营和全部匹配订单明细，不限最近一百笔。
- “菜品与库存”勾选当前页菜品后点击批量上架/下架。失败保留选择并显示原因；任何一条越权整批失败。切换页码或搜索条件后清空勾选，避免操作隐藏记录。
