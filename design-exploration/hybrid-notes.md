# 第11套融合原型：顶部导航 + Bento Grid + 浮动工具栏

本轮根据用户指定的组合制作独立原型，入口为 `prototypes/11-studio.html`。原有十套保留，可在画廊与第11套比较。

## 页面结构

- 顶部：品牌、经营概览、预约订单、菜品与库存、学生反馈、大屏入口和管理员信息。
- 主区：12列 Bento，核销收入与三阶段预约队列权重最高；宽幅趋势、近期预约与菜品经营形成第二层；低库存与未回复反馈提供进一步操作入口。
- 底部：浮动外观的工具栏，包含查找工作、处理待接单、导出概览、刷新视图和专注模式。工具栏使用独立布局区域，不覆盖图表和订单。主画布可滚动。
- 专注模式：隐藏顶栏，保留主区和工具栏；可以恢复。不会改变 Mock 业务数据。

## 实现边界

独立 `assets/hybrid.js`、`assets/hybrid.css` 只对第11套生效；共享原型只补充一处布局接入。全部数据、订单抽屉、窗口过滤、导出和反馈演示沿用前一轮的共享实现。不接真实后端、不改现有 Vue 页面、路由、登录或权限。
