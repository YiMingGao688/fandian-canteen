# 统一 Mock 与交互说明

所有方案加载 `assets/data.js`，不连接后端。当前默认日期为 2026-11-05，与浏览当天时间无关。`mock-data.json` 是相同样本的机器可读版本。

| 字段 | 默认全校值 | 口径 |
|---|---:|---|
| revenue | 18,624 元 | 累计已完成取餐订单收入 |
| totalOrders | 1,258 笔 | 累计全部状态订单 |
| todayOrders | 186 笔 | 当日预约，不等于累计订单 |
| completed | 1,016 笔 | 累计核销订单 |
| pending | 18 笔 | 已付款待接单 |
| preparing | 32 笔 | 当前备餐中 |
| ready | 14 笔 | 当前待取餐 |
| 近七日收入 | 12,846 元 | 10/30—11/05 核销收入合计 |

三个窗口的收入、订单及队列相加等于全校汇总。品类按六种样本菜品核销份数聚合，总计 1,034 份；一笔订单可以有多份菜品，份数不能和核销订单笔数直接对比。

近期订单数据共六条，各方案按布局显示其中三至六条，不是 64 条进行中订单的完整清单；看板泳道的标题数量代表完整 Mock 汇总。午餐容量只展示指定六个时段的样本，与全天 186 笔预约不是同一范围。

近七日与前七日提供固定数据。为便于比较，窗口筛选后的趋势按窗口累计收入占比拆分（仅原型假设）；不是后端实际窗口日收入。品类则按各窗口样本菜品直接汇总。

可试用：选择管理范围、切换 7/14 天趋势、点订单详情、演示接单/备餐完成、打开库存与反馈、回复输入、快捷键 `/` 查找任务、下载当前范围 CSV、返回画廊、两套并排比较。修改只影响当前页面内存，刷新恢复样本。大屏入口仅展示说明，不访问真实后台。

各方案有不同的信息侧重，不要求同时暴露所有指标；同名字段的默认值与统计口径保持一致。图表坐标与条长按数据计算，颜色不代表无关的随机趋势。
